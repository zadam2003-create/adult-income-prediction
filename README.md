# Adult Income Prediction

This repository contains a small machine learning project built on the UCI Adult Income dataset.

## Goal
Predict whether an individual's income exceeds $50K based on demographic and employment features.

## Approach
- Load and clean the dataset
- Handle missing values and encode categorical features
- Train and evaluate classification models
- Analyze model performance and feature importance

## Contents
- `Final_Project_.ipynb` - Jupyter notebook with the full workflow
- `adult.csv` - dataset file

## How to run
Install dependencies and open the notebook:

```bash
pip install -r requirements.txt
jupyter notebook
```
